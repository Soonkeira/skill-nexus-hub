# Screenshots

Drop the README screenshots in this directory. The READMEs (English and 简体中文) reference the following filenames — keep them stable:

- `market.png` — the skill marketplace listing (search / tags / favorites visible)
- `skill-detail.png` — a skill detail page showing the install buttons
- `admin.png` — the admin console (e.g. the review queue)

Export as PNG at roughly 1600px width (or 2x device pixel ratio) so they stay crisp when embedded.
